# DropThatUni

- Use Bun, TypeScript, Svelte 5, SvelteKit, and Tailwind CSS. Keep `bun.lock` current.
- Frontend first. Do not add authentication, AI, scraping, or database integration without a request.
- Preserve the existing app family styling: Figtree, light sage `#cfd5c5`, dark black `#000`, warm foreground `#e9e3df`, orange `#ff7a30`, rounded glass pill header, collapsible sidebar.
- Default view is a ranked clean program list with milestone dots. Table view and the details panel share the same fields and checklist data.
- Be minimalist wherever possible across all pages, components, emails, documentation, and responses. Do not add unnecessary lines, text, slogans, taglines, explanatory filler, or redundant labels. Include only what helps the user understand or complete the task; preserve essential instructions, feedback, and accessibility text.
- Sample program data must remain clearly identified as illustrative.
- Verify with `bun run check` and `bun run build`, and inspect desktop/mobile light/dark layouts when browser access permits.
- Every Git commit uses the user's configured Git author and committer identity.
